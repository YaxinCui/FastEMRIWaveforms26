## Git 不等于运行环境和完整数据迁移

5 GB Kerr H5、Flux H5、其它外部轨道数据、虚拟环境、micromamba 依赖、native
构建与 wheel、运行时 overlay、Python 缓存不随此次提交上传，也没有删除它们。
外部原始证据仍留在 Ubuntu：

- exp01-waveforms 的 12 个 NPY：202,175,712 B；exp04-waveforms 的 2 个
  NPY：33,695,952 B，位于 worktree 外的 artifacts。
- exp12-benchmark-cpu/cuda 的 pair0_master.npz：各约 681 KB，同样在外部 artifacts。
- exp06→exp07、exp13→exp12、exp16→exp15、exp17→exp16 等跨实验 NPZ
  已保存在各自发布分支，但读取时要准备相应分支/目录。

历史 JSON 保存 Ubuntu 绝对路径和当时源码/原生文件 hash。Mac 上需要建立自己的
环境、取得所需数据、重定位路径；不能把单个 branch clone 说成完整可直接复跑。
源码与报告已同步，不宣称所有外部二进制/数据已同步。
